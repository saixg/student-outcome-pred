3. Data and Model Boundaries

Raw data: Preserve the downloaded dataset unchanged.

Training data: Used to fit preprocessing and candidate models.

Test data: Used for final evaluation, not for fitting
preprocessing.

Saved pipeline: Contains the fitted preprocessing and selected
classifier.

Metrics artifacts: Generated by the evaluation code and reused
by the app and documents.

Streamlit app: Collects inputs, invokes the saved pipeline, and
displays the output.

Submission documents: Use verified results and screenshots from
the actual implementation.

4. Three-Step Delivery Flow

Step 1 --- ML foundation

Input: Official dataset
Process: Inspect → define target/features → split → preprocess →
train → evaluate
Output: Saved model pipeline, metrics, and charts
Gate: A reloaded pipeline successfully predicts on a valid sample.

Step 2 --- Working app

Input: Saved pipeline and evaluation artifacts
Process: Build interface → validate form inputs → predict → display
actual metrics
Output: Working Streamlit application
Gate: App starts and produces predictions without retraining.

Step 3 --- Final verification and submission

Input: Working app, source code, actual results
Process: Test → capture screenshots → write README → prepare
documents
Output: Reproducible mini-project and three submission deliverables
Gate: All claims and metrics match the implementation.

5. Failure Handling

If the dataset or target column differs from expectations, inspect
it and update the plan before training.

If the model artifact is missing or incompatible, show a clear
error; never substitute a fabricated prediction.

If a metric cannot be calculated, report the reason rather than
inventing a value.

If the dataset includes features only available after the intended
prediction point, remove them or avoid claiming early-warning
capability.

If a prediction input is invalid, explain which input needs
correction.

If results are weak, report them honestly; do not select or describe
a model as best without measured evidence.

6. Final Success Criteria

The project is complete when:

The ML pipeline can be trained and evaluated reproducibly.

The saved pipeline reloads and predicts.

The Streamlit app uses that pipeline.

The app shows genuine evaluation results.

The README explains setup and execution.

The Lean Canvas, Concept Note, and PowerPoint are complete and
factually consistent.
